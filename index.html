지정한 사람의 DM에만
자동으로 공감 누르기

규칙(누구에게·어떤 이모지·몇 초 뒤·하루 몇 번)을 정하고, 가짜 대화로 먼저 동작을 확인하는 설계용 웹사이트입니다.

1. 규칙 설정 & 시험

규칙

여기에 없는 사람의 메시지에는 아무 일도 하지 않습니다.

시험 대화방

"받기"를 누르면 그 사람이 메시지를 보낸 것처럼 처리합니다. 점선 테두리 = 공감 대기 중.

2. 결과 기록

0건너뜀
0오늘 남은 횟수

    3. 설계

    1. 메시지 감지

      새 메시지가 오면 보낸 사람, 메시지 ID, 내가 보낸 건지를 읽는다.

    2. 판정 (위에서부터 하나라도 걸리면 중단)

      꺼짐 → 내 메시지 → 대상이 아님 → 이미 공감함(ID 기록) → 활동 시간 밖 → 하루 한도 초과 → 제외 조건(질문 등).

    3. 지연 예약

      최소~최대 사이 무작위 초 뒤에 실행. 기다리는 동안 대화가 지워지면 취소.

    4. 공감 실행

      선택한 이모지로 반응하고, 성공/실패와 이유를 기록에 남긴다.

    5. 저장

      규칙·공감한 메시지 ID·오늘 횟수는 localStorage(나중엔 chrome.storage)에 저장, 날짜가 바뀌면 횟수 0.
    현실 제한
    일반 웹사이트는 인스타그램 DM을 읽거나 공감을 누를 수 없습니다(다른 사이트의 화면·로그인은 브라우저가 막고, 개인 DM용 공식 API도 없음). 그래서 이 페이지는 규칙 로직을 검증하는 시뮬레이터이고, 실제 연결은 인스타그램 페이지 안에서 도는 방식이 따로 필요합니다. 또 자동화는 인스타그램 약관에 어긋나 계정 제한 위험이 있어, 지연·하루 한도를 둔 것입니다.

    4. 확장프로그램 내려받기

    위 규칙을 실제 인스타그램 DM에서 쓰는 개인용 크롬 확장프로그램입니다.

    확장프로그램 받기 (.zip · 약 12KB)
    1. zip 파일을 받아 압축을 풉니다.
    2. 크롬 주소창에 chrome://extensions → 오른쪽 위 개발자 모드 켜기.
    3. 압축해제된 확장 프로그램을 로드합니다 → 압축 푼 폴더 선택.
    4. 인스타그램 탭을 새로고침한 뒤, 확장 아이콘에서 규칙을 정하고 켜기.

    웹스토어 확장이 아니라 직접 불러오는 방식이라 크롬이 "개발자 모드" 경고를 띄울 수 있습니다. 부계정으로 먼저 시험하세요.
